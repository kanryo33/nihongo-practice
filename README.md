# 日本語 基礎練習

日本語学習者向けの基礎練習ツール集。**5 つの独立した HTML ツール**を 1 つのプロジェクトにまとめました。

- **オンライン**: <https://kanryo33.github.io/nihongo-practice/>
- **ローカル**: `index.html` をブラウザで開くだけ（サーバー不要）

## 収録ツール

### 1. 五十音ランダム練習（`kana.html`）

- ひらがな・カタカナをランダム出題
- カードをクリックするとローマ字が表示
- 基本五十音 / 濁音・半濁音 / 拗音 を選択可能
- 1 〜 10 文字まで同時に表示

### 2. 数字・日付・時刻 練習（`suuji.html`）

- 数字（1 〜 8 桁）をランダム出題
- 年月日・時刻（時:分）の読み方練習
- 「読み方表示」ボタンで正しい読みを確認

### 3. 漢字たまご 練習（`kanji.html`）

- **漢字たまご 初級**（22 ページ / 284 字）と **初中級**（46 ページ / 564 字）を収録
- 教材を選んでページ番号を入力すると、該当ページの漢字カードを生成
- 複数ページの指定可能（例：`10 11 12`）
- カードクリックで個別反転、「一括反転」で全部まとめて反転

### 4. 単語カード 四語練習（`words.html`）

- できる日本語 初級 / 初中級 / 中級 ＋ 文法Buddy JLPT N3 を収録（合計約 4,600 語）
- 日・英・中・ネパール語 の 4 言語対応（课堂上投影用）
- レベル→課 の 2 段ドロップダウン、カード反転、2 モード（漢字→読み・意味 / 外語→日本語）
- キーボード操作（Space 反転、← / → 切替）、**昼間（ライト）テーマ固定**
- 出典：旧 `dekiru` リポジトリ（単語カード機能を統合）

### 5. JLPT 過去問 课堂演示（`jlpt.html`）

- 旧 `JLPT` リポジトリの「课堂演示モード（`classroom.html`）」のみを統合（問題管理システム本体は含まず）
- **N5〜N1 全 10,504 題**を収録（文字词汇 / 语法 / 读解 / 听解）
- 等级・分類・試験回（年月）で筛选し、大屏 1 题ずつ演示
- 文字大・模块明確（投影 / 大テレビ後列も可読）、听解は音声プログレスバー付き、读解は文章大字 + 展開 / 収納
- キーボード操作（← / → 切替、Space / Enter 解答表示、F 全屏）
- 音声は外部ホスト（`https://jlpt-audio-6vc.pages.dev/`）から再生、題図 397 枚を同梱
- **昼間（ライト）テーマ固定**、背景は工具包共通の模糊草坡（`.page-bg`）、主色を工具包緑（`#0f7a40`）に統一

## ファイル構成

```
index.html      ← ランディングページ（5 つのツールへのリンク）
kana.html       ← 五十音ランダム練習
suuji.html      ← 数字・日付・時刻練習
kanji.html      ← 漢字たまご ページ別練習（初級 22 頁 / 初中級 46 頁）
words.html      ← 単語カード 四語練習（できる日本語 初級〜中級 ＋ N3）
jlpt.html       ← JLPT 過去問 课堂演示（N5〜N1 全 10,504 題）
data/questions.js ← JLPT 题目データ（~20MB）
images/         ← JLPT 题图 397 枚（~125MB）
logo.png        ← JLPT ロゴ
```

## デザイン

landing ページは統一されたUI：
- 背景：右側に `assets/hero-34-bg.jpg` の自然插画を配置
- カード：白 + 18px 角丸 + 軽い影、hover で上移 + 緑枠
- ボタン：8px 角丸 + hover 上移、緑（#0f7a40）アクセント
- フォント：Inter / Noto Sans JP + system-ui フォールバック

統合ツール（`words.html` / `jlpt.html`）は工具包共通の緑テーマ：
- 主色：`#0f7a40`（工具包緑）。等级バッジは N5〜N1 の意味色を維持（N5 緑 / N4 青 / N3 黄 / N2 橙 / N1 赤）
- 背景：工具包共通の模糊草坡（`.page-bg` + `assets/hero-34-bg.jpg` を `opacity:.16; filter:blur(12px); transform:scale(1.06)`）
- 左上に固定の「← ホーム」返回键（`.back-btn`）で landing に戻る
- **昼間（ライト）テーマ固定**（ダーク / 自動切替なし）
