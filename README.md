# 日本語 基礎練習

日本語学習者向けの基礎練習ツール集。「五十音」と「数字・日付・時刻」の 2 つの練習アプリを 1 つのプロジェクトにまとめました。

## 使い方

- **オンライン**: <https://kanryo33.github.io/kana/>
- **ローカル**: `index.html` をブラウザで開く（サーバー不要）

## 収録ツール

### 1. 五十音 ランダム練習（`kana.html`）

- ひらがな・カタカナをランダムに出題
- カードをクリックするとローマ字が表示
- 基本五十音 / 濁音・半濁音 / 拗音 を選択可能
- 1 〜 10 文字まで同時に表示

### 2. 数字・日付・時刻 練習（`suuji.html`）

- 数字（1 〜 8 桁）をランダム出題
- 年月日・時刻（時:分）の読み方練習
- 「読み方表示」ボタンで正しい読みを確認

## ファイル構成

```
index.html    ← ランディングページ（2 つのツールへのリンク）
kana.html     ← 五十音練習アプリ
suuji.html    ← 数字・日付・時刻練習アプリ
```
